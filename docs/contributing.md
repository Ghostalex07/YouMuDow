# Contributing

## Setup Development Environment

```bash
git clone <repo>
cd YouMuDow
pip install -e ".[dev]"
```

## Code Style

- Follow PEP 8
- Use type hints
- Write docstrings

## Testing

```bash
pytest
```

## Submitting Changes

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Submit a pull request
